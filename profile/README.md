# Open Brand Exchange

**An open standard for exchanging product content between brands and retailers.**
A brand publishes its products once: texts, prices, sizes, materials and images. Every retailer pulls them from the brand's own portal in the same format. No vendor lock-in, no middleman, free to implement.

## Repositories

| | |
|---|---|
| [**spec**](https://github.com/openbrandexchange/spec) | The protocol: OpenAPI, JSON Schema, vocabularies, fixtures, conformance tests |
| [**obx-go**](https://github.com/openbrandexchange/obx-go) | Go SDK, `obx` CLI and the conformance suite |
| [**node-go**](https://github.com/openbrandexchange/node-go) | Brand/retailer portal in Go: one binary |
| [**node-php**](https://github.com/openbrandexchange/node-php) | Brand/retailer portal in PHP: runs on shared hosting |
| [**node-ts**](https://github.com/openbrandexchange/node-ts) | Brand/retailer portal in TypeScript: Cloudflare Workers or Bun |
| [**admin-ui**](https://github.com/openbrandexchange/admin-ui) | The web interface shared by all portals |

Current version: **0.3.1**. Try the [online checker](https://openbrandexchange.com/en/developers/) on your own portal.
